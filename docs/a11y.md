# Accessibility notes (plan P4-9, 4.12)

Status as of the P4-9 task. What is done, what is tested, and the gaps that remain open on purpose.

## Done

- **Theme contrast** is enforced by a unit test (`ThemeContrastTest`): every text/background pair of both themes holds
  at least 4.5:1 (G-THEME).
- **Icons**: Material Icons only (no emoji/glyph icons); decorative icons have `contentDescription = null`, action icons
  (expand/collapse, copy, dismiss, previous/next match) have descriptive content descriptions.
- **Keyboard shortcuts** (4.11, no single-letter shortcuts): F5 / Ctrl+R capture - Ctrl+L Live - Ctrl+F focuses the tree
  search - Enter / Shift+Enter walk the search matches - Esc clears the search and cancels a running capture -
  Ctrl+Shift+C copies the best selector - Alt+Up selects the parent - arrows move / expand / collapse in the tree.
  Verified by Compose UI tests where a key event can be injected deterministically.
- **Focus**: the tree pane, its search field and the Inspect screen are focusable; the tree keyboard model
  (move / expand / collapse / parent) is unit-tested; dialog hosts commit with Enter and cancel with Esc.
- **Tree rows** carry text semantics (label + secondary) with badges as text, so screen readers read structure, not pixels.

## Tested on CI

- Shortcut key handling (F5 capture, Ctrl+L Live, Ctrl+Shift+C copy) through the Inspect screen's key handler.
- Theme contrast in both themes; icon content descriptions by presence; dialog Enter/Esc behaviour.

## Known gaps (need a human, tracked in docs/MANUAL_QA.md)

- **Accessibility Insights FastPass run** on a real Windows display: not possible from CI. Compose Desktop exposes
  limited accessibility on Windows (plan 4.12 says so explicitly); the FastPass results and fixes land here.
- **Keyboard-only walkthrough of the core loop** end to end (capture to copy) - the pieces are keyboard-operable and
  tested individually; the full walkthrough needs a real session.
- **Tooltips** are drawn for hovered canvas elements; hover tooltips for toolbar buttons are a gap.
- **Text scaling at 150 %**: layout may clip; needs a real display check (Appendix E product quality row).
- **Focus order** beyond the natural layout order has not been tuned.
