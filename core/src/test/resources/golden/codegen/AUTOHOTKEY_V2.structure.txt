### automation id
; AutoHotkey v2 with UIA-v2 (copy UIA.ahk into a Lib folder): https://github.com/Descolada/UIA-v2/wiki
#Requires AutoHotkey v2.0
#include <UIA>

window := UIA.ElementFromHandle("ahk_pid 4242")  ; the process id changes on every run; "ahk_exe <name>" is stable
element := window.FindElement({AutomationId: "num1Button"})
element.Click()
