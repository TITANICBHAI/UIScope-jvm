Environment and limitations

Know what Windows accessibility exposes.

Elevated application windows

Windows restricts a normal-privilege process from inspecting elevated windows. If the target runs as administrator, run UIScope as administrator too.

Accessibility provider coverage

Some applications expose limited accessibility information. Chromium/Electron, Qt and Java applications may need their accessibility support enabled first.

Display scaling

Multi-monitor setups with different DPI settings can affect highlight alignment. Check per-monitor display scaling if bounds look offset.

Helper availability

The Windows UI Automation helper has a self-test and a retry path. See the troubleshooting guide for .NET Framework 4.8 and security-software issues.

A secure or protected window may block capture. UIScope reports a capture limitation rather than guaranteeing access to every screen.
