Desktop UI inspection for developers

See what your UI is made of.

UIScope is a Windows desktop UI inspector for developers and test engineers. Inspect Windows application windows or connected Android devices through ADB, explore element hierarchies, evaluate selectors, save snapshots and compare captures.

A practical automation workflow

Understand the element before you automate it.

A useful selector starts with understanding the target. UIScope makes the hierarchy, attributes, bounds and selector match results visible before you move into your test framework.

  • Inspect element attributes and the selected node's path.
  • Evaluate selector candidates against the captured tree.
  • See match counts, warnings and a reliability verdict.
  • Generate code for supported automation frameworks.

Designed around local work

Your captures stay on your machine.

UIScope's documented privacy model has no telemetry, analytics, accounts or crash uploads. Snapshots are stored locally; the app has only two optional network actions.

No telemetry or account

No analytics, crash upload or account system. Inspection data and saved snapshots remain in the local UIScope data folder.

Supported environment

Windows desktop host. Windows and Android targets.

UIScope is a desktop application. Its Windows target inspects Windows application windows; its Android target inspects a connected Android device through ADB.

Desktop host

Windows 10 (1809+) & Windows 11

The documented 1.0 desktop environment. Both Windows window inspection and Android device inspection are available in the Windows desktop application.

Connected target

Android device via ADB

USB debugging or Android wireless debugging lets UIScope list devices, capture the UI hierarchy and screen, and inspect elements.

New in 1.0.2

The two things UIScope is for, made dependable.

Version 1.0.2 is built around seeing an Android screen and inspecting a Windows app without guessing what went wrong.

The phone’s screen shows up first

The screenshot appears the moment it is captured; the elements fill in behind it. If they cannot be read, the screen stays and a banner says why.

Windows: choose a window, go to it

Minimized windows are restored and brought forward, then UIScope returns with the result. Pick mode labels the element under your pointer.

Help, support and changes in plain sight

Version, website, support, documentation and one-click diagnostics in the app, plus a “What’s new” window after every update.
