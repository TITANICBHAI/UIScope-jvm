Build from source

For developers who want to run the current code.

The repository documents a JDK 21 toolchain and Gradle wrapper. On Windows, use the batch wrapper:

gradlew.bat check
gradlew.bat :app:run

Packaging tasks are documented in the repository, but use the release page for a verified, published installer when one becomes available.
