Frequently asked questions

Straight answers about targets, selectors, privacy and releases.

A concise reference for what UIScope does, which environments it documents, how Android connectivity works and what is currently available.

What is UIScope?

UIScope is a Windows desktop UI inspector from TBTechs. It inspects Windows application windows through UI Automation and Android devices through ADB, showing element hierarchies, screenshots, properties, selectors, snapshots and capture comparisons.

Is UIScope an Android app?

No. UIScope is a desktop application. Its Android target inspects a connected Android phone or tablet from the desktop through ADB.

Which desktop operating systems are supported?

The current source documentation identifies Windows 10 version 1809 or later and Windows 11 as the supported desktop environment. macOS and Linux are not documented as supported packaged desktop hosts for the current 1.0.1 source.

Can UIScope inspect both Windows apps and Android devices?

Yes. The Windows target uses Windows UI Automation to inspect desktop windows. The Android target uses ADB to inspect a connected device.

Does Android inspection require USB?

USB debugging is supported. Android wireless debugging can also pair and connect over a reachable network.

What can I export?

The Inspector supports JSON, XML, outline text and PNG exports, with redaction options. Saved snapshots can also be exported as .uiscope bundles.

Which automation frameworks can receive generated code?

The current source includes uiautomator2, UI Automator (Kotlin), Appium Java, Appium Python, Maestro, XPath, pywinauto, FlaUI, AutoHotkey v2 and PowerShell.

Where are snapshots stored?

On Windows, UIScope stores data under %LOCALAPPDATA%\UIScope. Snapshots are local and are not automatically synced to a cloud service.

Does UIScope collect analytics or upload captures?

The repository privacy policy states that UIScope has no telemetry, analytics, crash uploads or user accounts. It documents two optional network actions: an update check and an explicitly requested platform-tools download.

Is a current installer available?

The repository source version is 1.0.1, but a matching installer for that rebuild has not been published. Check the Downloads page and the official release page for current status.

Why might a Windows or Android element be missing?

The target application may expose limited accessibility information, run at a higher privilege level, or present a secure screen. Review the troubleshooting guide for Windows UI Automation, ADB and accessibility-provider setup.

For setup errors, consult the official troubleshooting guide ↗. For privacy details, read the repository privacy policy ↗.
