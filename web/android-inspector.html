Connect a device

USB or Android wireless debugging.

UIScope's Android target uses Android Debug Bridge (ADB) from the desktop application. Enable USB debugging on the device, connect it and approve the debugging prompt. Wireless debugging can pair and connect over the same network.

  • Find an existing ADB installation or choose its path.
  • Download Google's platform-tools from within the app when needed.
  • List connected devices and watch for connection changes.
  • Capture the hierarchy and screenshot of the current screen.

Connection notes

ADB permissions and device state matter.

Authorize the computer

Unlock the device and approve the “Allow USB debugging?” prompt. If no prompt appears, revoke existing USB debugging authorizations in Developer options and reconnect.

Wireless debugging

Use Developer options → Wireless debugging to pair and connect. Both devices need network reachability; networks with client isolation can prevent pairing.

ADB version conflicts

If another platform-tools installation is already running, point UIScope at that exact adb executable to avoid competing ADB servers.

Secure screens

Some protected or secure app screens can block capture. The app surfaces a capture hint rather than promising visibility into every screen.
