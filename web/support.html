Support

Get UIScope working, or get help fast.

Most problems are one setting away. Start with the quick fixes below; if they do not solve it, send the diagnostics from the app and we will see exactly what UIScope saw.

Quick fixes

The five things that account for most problems.

Each one is a message you may see in UIScope, with what to do about it.

My phone’s screen does not appear

Plug in with a data cable, unlock the phone, turn on Developer options → USB debugging and tick Always allow in the prompt on the phone. UIScope shows the screen first and the elements a moment later. If the screen is blank, check the banner above it: it names the reason.

The screen shows, but there are no elements

Android could not read the elements of that screen: a video, a game, something animating, an app that blocks accessibility, or another automation tool (Appium, uiautomator2, Maestro) holding the device. Pause the animation or stop the other tool, then press Capture now.

The picture is solid black

The app marks its window as secure (banking, DRM video, some password screens) and Android refuses to capture it. UIScope says so with a banner; the elements can still be read where the app allows it.

A Windows window does not come to the front

Choosing a window restores it if it is minimized and brings it forward before the capture; UIScope then returns with the result. If Windows refuses (rare), UIScope says so and still captures. Use Show window to bring it up yourself. The behaviour can be switched off in Settings → Windows.

“That window runs as administrator”

Windows does not let a normal program read an administrator’s window. Start UIScope as administrator (right-click → Run as administrator) and choose the window again.

UIScope cannot find adb

Open Settings → Android and use Download platform-tools, or point UIScope to an adb you already have. Unplug and replug the phone afterwards.

Still stuck?

Send us what UIScope saw, in three steps.

1. Copy diagnostics

In UIScope open Help and press Copy diagnostics. It lists the version, your system, what UIScope sees of your phone or window and the last error code. It never contains anything from your screens.

2. Open a request

Use the support request button above. Say what you did, what you expected and what happened instead. A screenshot of the banner helps; check it for private information first.

3. Paste and send

Paste the diagnostics into the request. Requests with diagnostics can usually be answered without a round of questions.

UIScope is open-source software supported through GitHub. There is no phone line and no guaranteed response time; every request is read.
