Product capabilities

A UI inspection workflow built around the element tree.

UIScope brings live capture, visual selection, selector analysis, code generation, saved snapshots and capture diffs into one Windows desktop tool.

Read the quick start →Selector capabilities
01 · Capture and inspect

See the structure behind the screen.

Capture a Windows window or connected Android screen. Navigate the element hierarchy and use the screenshot canvas to relate nodes to visible controls.

⌗

Element hierarchy

Navigate nested controls, expand or collapse subtrees, search within the tree and preserve selection as you inspect a capture.

◎

Screenshot canvas

View the captured screen, zoom and pan around the canvas, hover elements and click to select the corresponding node.

▣

Element details

Review selector information, properties and the selected element's path in the details workspace.

02 · Understand selectors

Evaluate candidates against the captured hierarchy.

The selector engine evaluates candidate strategies, reports matching elements and surfaces warnings and a reliability verdict. Generated code is available for supported targets.

Selector evaluation

Candidate expressions are evaluated against the current element index. The selector view displays match counts, warnings and reliability guidance.

Ten code-generation targets

Generate snippets for Android and Windows automation workflows, including Appium, UI Automator, Maestro, pywinauto, FlaUI and PowerShell.

Read selector and code-generation details →

04 · Built for local inspection

Useful without an account or telemetry.

Saved snapshots and settings live in the local UIScope data folder. The documented network actions are optional update checks and an explicitly requested platform-tools download.

Windows desktop application

Documented desktop support is Windows 10 version 1809 or later and Windows 11. Android inspection uses ADB from the desktop host.
