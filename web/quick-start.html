Quick start

From first launch to your first useful capture.

Set up the Windows desktop application, choose a Windows or Android target, inspect an element and save the result as a snapshot.

Check release status →Build from source ↗
Before you begin

Check the host and target.

The current repository documents Windows 10 version 1809 or later and Windows 11 as the supported desktop environment. Android inspection requires a connected device and ADB access.

Inspect a Windows app

Run UIScope on a supported Windows desktop with the target application open. Elevated windows require UIScope to run with matching administrator privileges.

Inspect an Android device

Enable Developer options and USB debugging, connect the device and approve the computer's debugging authorization prompt. Wireless debugging is also supported.

Installer status: The repository's current source version is 1.0.2; its installer is attached to the matching GitHub release (see the Downloads page). The source repository includes build instructions for developers.
Path A · Windows app

Capture a Windows application window.

Open UIScope and run the helper self-test.

The Windows UI Automation helper is checked when the app starts. If it is unavailable, use the retry action and the troubleshooting guide.

Choose a window.

Open the window picker and select the application you want to inspect. You can also use the Pick element workflow to target a visible control.

Capture and explore.

Capture the window, browse the tree and canvas, and open the Selector, Properties or Path details.

Path B · Android device

Capture an Android screen through ADB.

Enable USB debugging.

On the device, enable Developer options and USB debugging, connect it to the Windows computer and accept the debugging authorization dialog.

Confirm ADB.

UIScope looks for an existing adb executable. You can browse to one or use the app's explicit, checksum-verified platform-tools download flow.

Select the device and capture.

Choose the connected device and use Capture now. The tree, screenshot canvas and element details are then available in the Inspector.

Path C · Selector

Test a selector before copying code.

Select an element from the tree or canvas.

Open the Selector tab to view candidates for that element.

Review the verdict and match count.

Check reliability guidance and warnings. Test the selector and inspect the matched path.

Choose a target and copy the snippet.

Pick one of the supported framework targets, copy the generated code and validate it in your test project.

Path D · Save a reference

Save a snapshot and compare later.

Save the current capture.

Use the snapshot action to store the tree and screenshot locally.

Organize your snapshot library.

Search, sort, pin and annotate saved captures. Open a saved snapshot offline when you need a reference.

Compare with a later capture.

Open Compare, choose two sources, review Added/Removed/Changed/Moved results and export JSON or text.

Export options

Take the inspection data with you.

The Inspector export dialog supports JSON, XML, outline text and PNG, with redaction options. Snapshots can also be exported as portable .uiscope bundles.
